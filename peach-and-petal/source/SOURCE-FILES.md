# Peach & Petal — Source File Guide

These SVGs are editable starter scaffolds. Replace them with manually created Illustrator/InDesign/Photoshop/Figma source work.

## Recommended working files

```text
peach-and-petal/
├── working/
│   ├── PNP_identity_master.ai
│   ├── PNP_packaging_master.ai
│   ├── PNP_brand-guide.indd
│   ├── PNP_mockups.psd
│   ├── PNP_campaign.fig
│   └── PNP_motion.aep
├── final/
│   ├── web/
│   ├── print/
│   └── motion/
└── source/
```

## Production notes

- Keep logos vector.
- Build packaging on real dielines once dimensions are chosen.
- Use linked/high-resolution imagery in InDesign.
- Keep print files in CMYK with appropriate bleed.
- Export web case-study imagery separately in RGB.
- Outline fonts only in production copies, not editable masters.
- Preserve one packaged InDesign folder for the final brand guide.
