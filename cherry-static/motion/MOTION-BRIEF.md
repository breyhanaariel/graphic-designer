# Cherry Static — Motion Brief

## Piece 1: Kinetic Festival Title
**Length:** 4–6 seconds  
**Formats:** 1080×1920 primary; 1080×1080 secondary

Suggested rhythm:
1. CHERRY enters oversized and partially cropped.
2. STATIC collides/slides into the composition.
3. Texture or image layer flashes/reveals.
4. Date/location information snaps into a strict grid.
5. End card resolves long enough to read.

## Piece 2: Social Ad
**Length:** 6–10 seconds  
**Goal:** communicate event + date + CTA without becoming an unreadable montage.

Demonstrate: text animators, masks, track mattes, posterized/texture treatment, scale/position easing, controlled frame holds, and export for vertical social.

Use the SVG only as a timing/composition sketch. Final motion should be rebuilt manually in After Effects.
