# Cherry Static — Source File Guide

The included SVGs are size/composition scaffolds and are intentionally easy to replace.

## Recommended working files

```text
cherry-static/
├── working/
│   ├── CS_type-and-marks.ai
│   ├── CS_collage-master.psd
│   ├── CS_program.indd
│   ├── CS_campaign-system.fig

├── scans/

├── final/

```

## Production notes

- Capture handmade textures at high resolution.
- Keep the hero poster print-ready with bleed and a CMYK version.
- Test expressive typography at realistic viewing distances.
- Preserve clean editable text in working masters.
- Make social variants from the campaign system rather than cropping the poster blindly.
- Design vertical motion natively for 9:16.
