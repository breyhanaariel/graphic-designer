## Evidence standard

A tool should only be emphasized in the final README when the case studies visibly demonstrate it. The strongest portfolio evidence is a final artifact plus a brief note explaining **why that tool was useful**.

## AI-assisted workflow

AI may be used for early ideation, production assistance, background extension, variation exploration, or other supporting tasks. Final art direction and portfolio work should remain designer-led, and any meaningful generated imagery that survives into a final piece should be disclosed.
