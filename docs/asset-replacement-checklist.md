# 🎨 Portfolio Asset Replacement Checklist

The files currently in this repository establish layout, deliverable coverage, dimensions, naming, and case-study storytelling. They are **scaffolding, not final authored portfolio art**.

Use this checklist as each project is completed manually.

## Replace first

- [ ] Final logo/wordmark
- [ ] Custom illustration and/or photography
- [ ] Hero/key visual
- [ ] Typography choices and licensed fonts
- [ ] Final palette and accessibility checks
- [ ] Primary mockups
- [ ] Motion exports
- [ ] Any AI-assisted exploratory imagery with original finished art

## Replace next

- [ ] Packaging dielines and final labels
- [ ] Social and paid-media variations
- [ ] Presentation/report pages
- [ ] Posters, OOH, signage, and merchandise
- [ ] Canva/Figma editable templates
- [ ] Final production PDFs
- [ ] Process sketches and development photos

## Before publishing each case study as final

- [ ] Change all scaffold labels from **Concept Scaffold** to final project language
- [ ] Make sure no generated visual remains unless intentionally disclosed
- [ ] Add screenshots/photos of real manual process where useful
- [ ] Confirm every software claim is supported by visible work
- [ ] Add alt text/captions to important images
- [ ] Export web images at sensible sizes
- [ ] Add final source/export links
- [ ] Proofread copy for fictional-client language
- [ ] Keep the project labeled **Independent Concept Project**
- [ ] Never invent client approval, sales lift, audience metrics, testimonials, or campaign results
